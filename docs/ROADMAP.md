# AK Dev Arena — Roadmap to v1.0 (Full & Final)

10 phases, Phase 0 → Phase 9. Every phase ends with a **working, tested, tagged** version.

| Phase | Name | Delivers | Version |
|---|---|---|---|
| **0** | Foundation | Tauri+React shell, FastAPI+LiteLLM sidecar, Chat Mode, key vault, CI | v0.1 ✅ |
| **1** | Code Mode | File tree, editor, Tab autocomplete, `@` mentions, diff accept/reject, `.akrules`, repo map, git undo | v0.2 |
| **2** | Agent Mode | Plan→act→verify loop, todos, `/commands`, hooks, subagents, MCP, Docker sandbox, browser | v0.3 |
| **3** | Manager View | Mission control, parallel agents in isolated workspaces, queue + reusable workflows | v0.4 |
| **4** | Build Mode | Templates, prompt-to-app, live preview + HMR, auto-fix loop, deploy | v0.5 |
| **5** | Review Mode | Separate review agent, security checks, PR creation | v0.6 |
| **6** | Voice Mode | Silero VAD + Whisper + Edge-TTS, wake-word, confirmations ⭐ killer feature | v0.7 |
| **7** | Free & Local | Ollama deep integration, free-tier routing, model picker, cost tracker | v0.8 |
| **8** | Polish | Cmd+K palette, themes, onboarding, settings, auto-updates, Tauri packaging | v0.9 |
| **9** | Release | Beta, docs site, demo video, Win/Mac/Linux installers, public launch | **v1.0 🎉** |

## v1.0 definition of done
- [ ] All 6 modes working (Chat, Code, Agent, Build, Voice, Manager)
- [ ] Any API key + Ollama local both work
- [ ] Installers for Windows, macOS, Linux
- [ ] No crash in normal use; undo available for every destructive action
- [ ] Docs + demo video published

## Post-1.0 ideas
Cloud sync, mobile companion, agent/workflow marketplace, team collaboration.
